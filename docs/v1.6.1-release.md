# v1.6.1 — Final Visual Polish

Three local presentation corrections on Process and About, starting from accepted
v1.6.0 commit `d311313ea9ed7bf4f222647a95f3ccb937466932`. This is a corrective
pass; Home, Dream Flow and the storybook are unchanged.

## 1. Process desktop reassurance gutter

The tablet `:nth-child(odd)` rule removed left padding from the third item. Its
specificity beat the general desktop item rule when the grid became four columns.
“Joined-up delivery” therefore began at its divider instead of sharing its
neighbours' inset.

A third-item padding override inside the existing `min-width: 72rem` query restores
the same `clamp(1.5rem, 2.5vw, 2.5rem)` left inset as columns two and four. It is
34.15px at 1366px, 36px at 1440px and 40px at 1920px. The four tracks remain 304px
wide; rules, navy, typography, copy and row height are retained.

The 1024px view intentionally retains the existing two-column layout. Focused
grid screenshots and geometry are identical to baseline at 320, 390, 768 and
1024px in both motion preferences. No journey/rail or tablet/mobile rule changed.

## 2. Viki Nasch portrait framing

The existing 188×263 PNG has two pale source columns along its left edge. A
non-semantic clipping span retains the original 5.5rem square and rounded geometry.
The original image receives a 1.04 scale, with a 2px navy inset frame painted by a
pointer-transparent pseudo-element. The pale source edge is concealed, including
the rounded perimeter, without replacing or modifying the photograph.

Viki's face remains naturally framed. Oli's image treatment is unchanged; both
portraits retain 88px outer dimensions at ordinary text size. Source, alt text,
loading attributes and image bytes are unchanged. The small crop remains within
the source's horizontal resolution at ordinary size and 2× pixel density.

The required 200% text review exposed the existing fixed mobile profile grid's
crowding. Local flexible wrapping lets image and copy take separate lines only
when needed. A bounded leadership grid and emergency heading wrapping keep that
region contained at enlarged text. Normal-size page/profile geometry remains
unchanged across the review widths.

## 3. About confidence numbering

Before: a `div` containing four `article` blocks, each with an aria-hidden `01–04`
span and a separate text column. After: a labelled `ul` with four `li` elements
and no index spans. Explicit `role="list"` retains list semantics when markers
are suppressed. No bullets, icons, pseudo-markers or replacement indices appear.

The released gutter now belongs to the text: headings and descriptions align
with the label and separators. All four titles and descriptions are unchanged.
Row padding, paragraph spacing, typography, content width and separator treatment
are retained. There are no cards or fixed heights.

Final visual review at 200% text found the existing 24rem column minimum squeezed
the neighbouring prose into the confidence rows at 1024px. Replacing that minimum
with zero retains the 0.85/1.15 proportions and all ordinary-size geometry while
allowing both columns to fit at enlarged text. A second visual pass confirms the
overlap is removed.
